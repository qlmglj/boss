# 网页版boss直聘-
利用自动打招呼去海投，可以筛选出自己岗位的关键词和可以屏蔽自己不想去的岗位关键词
使用方法：利用Edge浏览器的扩展功能去 装 Tampermonkey（油猴） → 新建脚本 → 把 boss-auto-greet.user.js 里的代码全文复制粘贴进去
设招呼语：右上「消息」→ 设置 → 招呼语（脚本发的就是这段）
跑：打开 zhipin.com/web/geek/jobs，右下角出现面板 → 先勾「试运行（不发送）」看筛选对不对 → 取消勾选正式跑
